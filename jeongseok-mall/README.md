# 정석몰

국내 고객용 쇼핑몰입니다. 상품을 보고, 담고, 결제하고, 주문을 다시 확인합니다. 운영자는 상품과 주문 상태를 관리합니다.

로컬에서 바로 실행하는 데모입니다. 카드·간편결제는 외부 결제사를 호출하지 않고, 서버가 바로 승인합니다. 카드 번호는 저장하지 않습니다.

## 실행

Node.js 22 이상이 필요합니다.

```bash
cd jeongseok-mall
npm install
npm start
```

브라우저에서 http://127.0.0.1:3000 을 엽니다.

다른 포트나 데이터베이스 파일이 필요하면 `PORT`, `HOST`, `DB_PATH`를 지정합니다.

```bash
npm run verify
```

상점 흐름(목록, 검색, 장바구니, 비회원 결제, 주문 조회, 취소, 배송 상태)을 로컬에서 확인합니다.

## 데모 계정

관리자 화면은 http://127.0.0.1:3000/admin 입니다.

- 이메일: `admin@jeongseok.local`
- 비밀번호: `jeongseok-admin`

고객 가입으로는 관리자가 되지 않습니다. 이 비밀번호는 로컬 데모용입니다.

## 결제와 배송

- 간편결제는 바로 승인됩니다.
- 카드 번호가 `0000`으로 끝나면 승인이 거절되고 주문은 만들어지지 않습니다.
- 기본 배송 설정은 상품 금액 50,000원 이상 기본 배송비 없음, 그 미만 3,000원, 도서산간 추가 4,000원입니다. 우편번호가 `63` 또는 `402`로 시작하면 도서산간으로 봅니다. 숫자는 관리자의 배송 설정에서 바꿀 수 있습니다.
- 서로 다른 분류의 상품도 주문 하나, 배송비 하나, 출고 하나입니다.
- 고객은 결제 완료와 상품 준비 중에서만 직접 취소할 수 있습니다.

샘플 분류 이름(분류 1, 분류 2, 분류 3)은 자리표시이며, 관리 화면에서 바꿀 수 있습니다.

데이터는 `jeongseok-mall/data/mall.db`에 저장됩니다. 파일을 지우면 처음 실행할 때 샘플 상품과 관리자 계정이 다시 만들어집니다.
